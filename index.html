About this experiment

The output is always a black-ink transparent PNG. Existing transparent artwork is preserved; paper photographs use local contrast, connected-component filtering, and automatic cropping. PDF pages and HEIC/TIFF images are decoded in the browser. A complex photograph may still require sensitivity adjustment or manual framing. This is an algorithm test bench, not a document-signing or identity-verification service.

Format libraries: PDF.js (PDF), heic-to (HEIC/HEIF), UTIF + pako (TIFF). GitHub Pages serves local copies of the decoders; a pinned CDN is a fallback for source-only local testing. Signature file content is never intentionally uploaded. Production integration should remove the CDN fallback and enforce a strict Content Security Policy.
